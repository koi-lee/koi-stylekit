# 风格目录扩充

**简体中文** | [English](catalogue-expansion.en.md)

2026-09-09：目录从 4 项扩展到 300 项，分为 9 个媒介分类、40 个风格家族与 260 个画法或构图变体。变体继承家族的媒介规则，再添加不同线条、肌理或构图处理；不等于 300 种独立艺术媒介。

新增配方自行撰写，未复制上游图片或配方。借鉴 yang0 的分类浏览方式与 threerocks 的配方组织思想；保留现有来源说明与许可证。上游数量随版本变化，不作为本项目完成度证据。

验收路径：分类或家族筛选 → 搜索编号 → 每页 24 项浏览 → 最多比较 3 项 → 选择配方 → 输入主题 → 预览与导出。中文和英文 README、贡献说明提供文档入口；界面和导出提示词仍为中文。

新增样图使用同一主题“一只猫在雨中撑着伞，主体完整，背景简洁。”、1:1 画幅，以 assets/catalogue 中 JSON 的 prompt_zh 原样调用内置 imagegen，无显式参考图。PNG 为生成原图，JSON 为当时实际输入快照。四项历史样图沿用原有主题和记录。生成进度以 styles.json 的 image 字段和实际文件为准。

所有新增样图属于单主题单次候选，尚未经用户逐项视觉验收；不宣称跨主题、跨模型稳定复现。连续线条、严格平涂、剪纸连接性和简洁背景等约束有偏离风险；固定色媒介在主题带指定颜色时可能冲突。自动导出成功不能代表这些视觉约束通过。

自动检查覆盖 300 个唯一编号、家族关系、支持用途及两种配色策略的导出、实际样图输入与当前配方的一致性。交付前需运行完整测试和浏览器路径检查；提交、推送与 CI 结果另记验收记录。
