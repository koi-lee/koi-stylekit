# Koi StyleKit 推广素材（草稿）

## 一句话介绍

Koi StyleKit 是一个开源的手绘插画风格目录：浏览 308 项配方（48 个风格家族与 260 个变体），选择配方，导出可复用提示词。

## 小红书 / 即刻 / 公众号短文案

做 AI 插画时，最难的常常不是“画什么”，而是“怎么稳定地画”。

我做了 Koi StyleKit：一个可以直接在浏览器使用的开源风格工具箱，收录 308 项配方，包含 48 个风格家族和 260 个变体，按风格家族、媒介和用途筛选，可以比较候选、查看样图，再导出中文提示词和 JSON 风格包。

它不会上传主题，也不会自动调用生图 API，适合先选风格、再去你熟悉的工具里生成。

在线画廊：https://www.starshoreai.com/koi-stylekit/gallery/

GitHub：https://github.com/koi-lee/koi-stylekit

以上为通用母稿；平台发布版本需单独核对当日规则，外链不保证每个平台均可使用。

## 60 秒演示脚本

0–08 秒：展示三张差异明显的样图，字幕“同一个主题，先选对画风”。

08–20 秒：搜索“纸雕”，切换风格家族，展示 300+ 配方和样图预览。

20–35 秒：打开详情，展示视觉构成、适用用途和验证状态；强调样图是候选效果，不承诺跨模型复现。

35–48 秒：输入“图书管理员把书递给读者”，选择用途和比例，生成中文提示词。

48–60 秒：复制提示词或下载 JSON，展示正式画廊入口和 GitHub README，说明 CLI / Skill 也可本地使用。

## 发布注意

- 使用自己的样图和仓库截图，不转载未获授权的第三方图片或提示词。
- 明确“候选样图”“浏览器端处理主题”“不保证跨主题复现”，避免夸大效果。
- 不使用“稳赚”“100%复现”“官方认证”等绝对化表述。
- 不购买流量、不刷互动、不诱导关注或私信；每个平台单独调整标题、标签和长度。

## 首发素材包（2026-09-11，待录制、未发布）

### 标题与正文母稿

标题：我把插画配方做成了一个能直接浏览的开源画廊

想给项目配图时，我经常知道要画什么，却说不清想要哪种画风。于是做了 Koi StyleKit：先看样图，再选配方，填上自己的主题，复制提示词到生图工具里使用。

现在整理了 308 项配方，分为 48 个风格家族和 260 个变体。我自己偏爱纸雕，也可以看看彩铅、版画等效果。网页不用安装，主题在浏览器里处理。它负责导出提示词，不会直接生成图片；样图也不保证换个主题或模型就能完全复现。

如果试过，欢迎说说：你选了哪种风格，用在什么内容上，哪一步不顺手。

### 录屏镜头表（约 45 秒）

| 时间 | 画面 | 口播 / 字幕 |
| --- | --- | --- |
| 0–6 秒 | 三种代表样图，选纸雕作为主角 | 先看画风，再写提示词。样图为 AI 生成候选。 |
| 6–14 秒 | 正式画廊搜索纸雕，打开家族 | 308 项配方，48 个家族与 260 个变体。 |
| 14–22 秒 | 打开详情，再选择风格 | 看用途和验证状态，选适合这次内容的。 |
| 22–33 秒 | 填“图书管理员把书递给读者”，预览 | 主题在浏览器处理，这一步导出提示词，不生成图片。 |
| 33–40 秒 | 复制，下载 JSON | 可以带到你常用的生图工具，也能保留风格包。 |
| 40–45 秒 | 正式画廊与 GitHub 页面 | 已开源，也支持 Python CLI 和 Agent Skill。 |

录制使用干净浏览器，隐藏账号、其他标签页与扩展浮窗。不要用加载动画暗示正在自动生图。若演示外部生图，单独标明工具、耗时和模型，不与画廊功能混淆。
