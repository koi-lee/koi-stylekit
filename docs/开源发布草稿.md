# v0.2.0-alpha 发布草稿（未发布）

建议仓库名：koi-stylekit。描述：A local-first illustration style gallery and prompt toolkit with a shared Python CLI and agent skill.

## 发布正文

Koi StyleKit 首个 Alpha：先看真实候选样图，再选择画风、填写主题并导出中文提示词。

- 三种候选画风：淡彩速写、双色孔版、彩铅日记。
- 网页、Python CLI 与 Skill 使用同一渲染器。
- 导出包含来源、配方版本、独立标题和验证状态。
- 固定配色遇到主题颜色时，可选择遵循画风或保留主题颜色。
- 本地运行，不调用生图 API，不上传主题到外部服务。

这是提示词与风格复用工具，不是在线生图平台。样图为 AI 生成的候选，跨模型稳定性、英文配方、MCP 尚未实现。配色提醒仅覆盖部分词语。

感谢 threerocks/hand-drawn-styles 的配方与流程启发，以及 yang0/handraw-style 的编号画廊和媒介分类思路。具体来源及许可见 ATTRIBUTION.md。

## 传播素材草稿

标题：我把挑画风、存配方、换主题，做成了一个本地工具

正文：做配图时，我经常遇到“上一张挺好看，下一张又变了”的问题。Koi StyleKit 尝试把风格描述保存下来：先看候选样图，选风格，填主题，导出提示词。首版有三种画风，网页和命令行共用配方，也准备了 Skill 入口。它不承诺每次生成一致，当前重点是让配方、来源和实际效果能被检查和复用。

视频分镜（约 40 秒）：问题与样图对照 → 选择双色孔版 → 输入绿色书本 → 演示配色取舍 → 导出提示词 → 展示功能边界。演示图片标明 AI 生成，明确样图是预先生成而非网页实时生图。

平台尚未选定，当前稿不直接发布。发布前核对目标平台现行 AI 标识、链接与推广要求，再按平台适配；不承诺避免限流。
